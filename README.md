# BFT uControl

Home Assistant integration for BFT uControl gates.

## Features

- Open gate
- Close gate
- Stop gate
- Gate status monitoring
- Automatic device discovery
- HACS installation
- Home Assistant UI configuration

## Installation

1. Open HACS.
2. Open the three-dot menu.
3. Select Custom repositories.
4. Add your GitHub repository URL.
5. Select Integration as category.
6. Install BFT uControl.
7. Restart Home Assistant.
8. Open Settings > Devices & Services.
9. Select Add Integration.
10. Search for BFT uControl.

Enter your BFT username and password.
